# 개인용 영어 학습 앱 요구사항 v2

> 개인 사용자를 위한 Android 영어 학습 앱의 MVP 요구사항이다.
> 핵심 목표는 회원·운영 기능을 만드는 것이 아니라, **매일 20분 동안 재미있고 실제적인 영어 표현을 학습하고 자동으로 복습하는 경험**을 제공하는 것이다.

---

## 1. 문제 정의

### 1.1 사용자

* 40세 성인 영어 학습자
* 하루 약 20분 학습 가능
* 매일 비슷한 시간에 학습 가능
* 개인 사용 앱이며 다중 사용자 서비스 운영은 고려하지 않는다.

### 1.2 기존 학습의 문제

1. 동화형 영어 콘텐츠는 성인에게 유치하게 느껴진다.
2. 단어를 별도로 정리하고 암기하는 과정이 번거롭다.
3. 기존 학습 앱의 문장이 지나치게 짧고 단순하다.
4. 실제 미국 원어민이 쓰는 자연스러운 표현을 배우고 싶다.
5. AI가 만든 대화나 이야기는 재미있지만:

   * 어떤 표현을 복습해야 하는지 관리하기 어렵다.
   * 이전에 학습한 표현을 다시 활용하기 어렵다.
   * 따로 정리하지 않으면 복습하지 않게 된다.

---

# 2. 목표

## 2.1 학습 목표

재미있는 콘텐츠를 통해 실제 미국 영어 표현을 반복적으로 익힌다.

최종적으로 다음 상황을 목표로 한다.

**여행지에서 현지인과 농담을 섞은 자연스러운 스몰토크를 막힘없이 주고받는다.**

목표 달성 기한은 두지 않는다.

---

# 3. 제품 원칙

1. 학습 시간은 하루 약 20분이다.
2. 학습 준비 작업을 최소화한다.
3. 사용자가 별도로 단어장을 정리하지 않는다.
4. 모르는 표현을 누르면 자동으로 복습 대상이 된다.
5. 이전에 저장한 표현은 새 콘텐츠와 퀴즈에서 반복 등장한다.
6. 콘텐츠는 성인이 읽어도 재미있어야 한다.
7. 실제 미국 영어에서 사용할 만한 자연스러운 표현을 우선한다.
8. AI는 필요한 부분에만 사용한다.
9. 개인 앱이므로 회원 관리, 다중 사용자 운영 기능 등은 구현하지 않는다.
10. 앱을 실행하면 가능한 한 바로 학습을 시작할 수 있어야 한다.

# 6. 데이터 저장

## 6.1 저장 대상

다음 데이터를 저장한다.

* 현재 영어 난이도
* 진단 결과
* 저장한 단어 및 표현
* 표현의 문맥상 의미
* 최초 저장일
* 최근 복습일
* 다음 복습 예정일
* 연속 정답 횟수
* 오답 기록
* 학습 완료 기록
* 스트릭
* 누적 저장 표현 수
* 암기 완료 표현 수

## 6.2 저장 방식

MVP 학습 데이터는 사용하는 Android 기기 안에만 저장한다. 구조화된 학습 기록은 Room에, 진단 완료 여부와 간단한 앱 상태·설정은 DataStore에 저장한다. 앱을 종료하거나 다시 실행해도 기존 데이터가 유지되어야 한다.

MVP에서 Supabase DB 저장, 기기 간 학습 데이터 동기화, Supabase Auth와 사용자별 RLS는 사용하지 않는다. 향후 여러 기기 간 동기화가 실제로 필요해질 때 인증과 클라우드 저장을 별도 기능으로 검토한다.

서버 기능은 AI API 호출 보호 등 필요한 범위로 제한한다. AI API Key와 서버용 비밀값은 Android 앱에 직접 포함하지 않는다.

# 7. 최초 레벨 진단

앱 최초 실행 시 한 번만 레벨 진단을 진행한다.

## 7.1 진단 방식

짧은 영어 문장과 질문을 보여준다.

예:

* 문장 의미 선택
* 자연스러운 표현 선택
* 간단한 빈칸 문제

진단 결과를 바탕으로 초기 난이도를 결정한다.

진단 완료 이후 일반 앱 실행 시에는 다시 진단하지 않는다.

---

# 8. 난이도 관리

초기 난이도는 진단 결과로 결정한다.

이후 다음 데이터를 활용해 난이도 변경을 **제안**한다(2026-09-30 개정, 백로그 034).

* 퀴즈 정답률
* 최근 학습 성과
* 저장하는 표현의 빈도
* 콘텐츠 내 표현 난이도

난이도는 대화/스토리 모드별로 1~5단계이며, 홈 화면에서 사용자가 직접 올리고 내릴 수 있다.
자동 판단은 강제로 바꾸지 않고 "올려볼까요/낮춰볼까요" 제안만 하며, 사용자가 수락하거나 유지한다.
라이브러리에서 지난 지문을 다시 읽은 세션은 제안의 근거로 쓰지 않는다.

난이도(레벨)는 다음 콘텐츠 생성 시 사용한다.

CEFR 같은 외부 등급 체계를 고를 필요는 없다.

# 9. 하루 학습 흐름

하루 학습은 약 20분이며 크게 두 단계로 구성한다.

**콘텐츠 학습 약 10분 → 퀴즈 약 10분**

---

## 9.1 Step 1. 학습 형식 선택

홈 화면에서 사용자가 직접 선택한다.

### 대화 모드

사람 사이의 자연스러운 대화.

예:

* 여행
* 호텔
* 카페
* 식당
* 직장
* 친구
* 가족
* 쇼핑
* 일상적인 잡담

상황은 매일 다양하게 생성한다.

2026-10-08 개정(백로그 053): 대화는 해외 여행에서 실제로 겪는 상황 목록(공항·숙소·식당·길 찾기·현지인과의 잡담 등)에서 매번 하나를 골라 생성한다. 직장·가족 등 비여행 상황은 당분간 만들지 않는다. 스토리와 대화 모두 독자 취향 지침(심리·관계 관찰, 미스터리·여행·역사, 드라이한 유머, 신파·잔인함 배제)과 최상위 원칙 '영어 공부라는 사실을 잊게 하라'를 따른다.

### 스토리 모드

성인을 위한 짧은 이야기.

톤:

* 유머
* 위트
* 약한 풍자
* 의인화 캐릭터 사용 가능

어린이 동화처럼 교훈적이거나 지나치게 단순한 이야기는 지양한다.

# 10. 콘텐츠 생성

## 10.1 콘텐츠 구성

새 콘텐츠는 다음 두 종류의 표현을 섞는다.

### 복습 표현

기존 복습함에 저장되어 있으며 현재 복습할 필요가 있는 표현.

### 신규 표현

현재 난이도에서 새롭게 학습할 표현.

초기 사용 등 저장 표현이 충분하지 않은 경우 신규 표현을 중심으로 생성한다.

## 10.2 콘텐츠 분량

약 10분 학습 가능한 분량을 목표로 한다.

너무 짧은 단문 모음보다는 문맥과 상황이 이어지는 콘텐츠를 생성한다.

---

# 11. 표현 학습

콘텐츠를 읽다가 모르는 단어나 표현을 터치할 수 있다.

예:

`That sounds a little sketchy.`

사용자가 `sketchy` 또는 해당 표현을 터치한다.

앱은 현재 문맥 기준 의미를 표시한다.

예:

**sketchy**
→ 좀 수상한 / 미심쩍은

단순 사전 번역보다 현재 문장에서의 의미를 우선한다.

뜻 조회가 성공하면 해당 표현을 자동으로 복습함에 저장한다.

별도의 "저장" 버튼을 누를 필요는 없다.

---

# 12. 표현 중복 처리

같은 표현이 다시 선택되더라도 중복 저장하지 않는다.

기존 기록을 유지한다.

유지해야 할 정보:

* 최초 저장일
* 복습 상태
* 정답 기록
* 다음 복습 예정일

---

# 13. TTS

대화 모드와 스토리 모드 모두 TTS를 제공한다.

지원 기능:

### 전체 재생

전체 콘텐츠를 처음부터 순서대로 읽어준다.

### 문장별 재생

각 문장 옆의 재생 버튼을 눌러 해당 문장만 들을 수 있다.

### 표현 재생

저장된 단어나 표현의 발음을 따로 들을 수 있다.

전체 재생과 개별 문장 재생이 동시에 겹치지 않아야 한다.

화자 목소리는 지문 생성 시 함께 받는 화자 성별(여/남/내레이터)에 맞춰 배정한다(2026-10-08 개정, 백로그 050). 성별 정보가 없으면 등장 순서로 배정한다.

---

# 14. 퀴즈

콘텐츠 학습 이후 약 10분간 퀴즈를 진행한다.

## 14.1 퀴즈 대상

다음 표현을 사용한다.

* 오늘 콘텐츠의 복습 표현
* 오늘 새로 저장한 표현
* 이전에 저장했고 오늘 복습 시점이 된 표현

따라서 오늘 콘텐츠에 나오지 않은 과거 표현도 퀴즈에 등장할 수 있다.

## 14.2 퀴즈 종류

MVP에서는 다음 유형을 사용한다.

### 객관식

영어 표현에 맞는 뜻 선택.

### 빈칸 채우기

문맥 속 빠진 표현 선택 또는 입력.

### 직접 입력 빈칸 (2026-10-02 개정, 백로그 043; 2026-10-07 개정, 백로그 045)

문맥 문장이 있고 연속 3회 맞힌(꽃 단계) 표현은 선택지 없이 직접 타이핑한다. 대소문자·구두점·공백은 무시하고, 첫 글자 힌트와 "모르겠어요"를 제공한다. 알아보기가 아니라 떠올려 꺼내는 연습이다.

### 문제 사다리와 처음 등장 카드 (2026-10-07 개정, 백로그 045~048)

퀴즈가 너무 어렵다는 사용자 판단으로, 표현의 성장 단계에 따라 한 칸씩만 어려워지게 한다.

* 처음 등장(한 번도 퀴즈에 나오지 않음): 카드로 표현·짧은 뜻·문장·발음을 보여주고 "알아요 / 모르겠어요"만 누른다. 어느 쪽이든 내일 다시 보기로만 잡고 정답·오답으로 세지 않는다. 점수 없음. 다음 날부터 씨앗 단계에서 한 칸씩 올라간다.
* 씨앗: 뜻 고르기 2지선다. 새싹: 4지선다. 잎: 빈칸에 들어갈 표현 고르기. 꽃: 직접 입력. 문맥 문장이 없으면 4지선다로 대신한다.
* 선택지는 생성 시 함께 받는 짧은 뜻(12자 안팎)으로 만들고 긴 설명은 정답 화면에만 보여준다. 짧은 뜻이 없는 표현이 섞이면 길이로 답이 드러나지 않도록 전부 긴 뜻을 쓴다(백로그 046).
* 틀린 문제는 그 퀴즈 끝에 한 번 더 나온다. 점수와 기록 없이 "다시 풀기"로 표시한다(백로그 047).
* 처음 등장 표현은 하루 5개까지만 보여주고 나머지는 다음 날로 넘긴다. 같은 날 다시 들어가도 그날 이미 본 카드 수를 뺀 만큼만 나온다. 복습 표현을 먼저 채운다(백로그 048). 주말 보스전은 카드 없이 문제로만 묻는다.

### 지문 이해도 질문 (2026-10-02 개정, 백로그 042)

지문 생성 응답에 한국어 질문 2~3개(선택지 4개, 해설)를 함께 받아 퀴즈 앞부분에 둔다. 인물이 왜 그렇게 말했는지, 다음에 자연스러운 대답은 무엇인지 같은 흐름 이해를 묻는다. 호출 횟수는 늘지 않고 출력 토큰만 소폭 증가한다(사용자 수락).

향후 필요하면 다른 문제 유형을 추가할 수 있다.

# 15. Spaced Repetition

표현마다 복습 상태를 관리한다.

기본 원칙:

* 틀리면 다음 복습 시점을 앞당긴다.
* 맞히면 복습 간격을 늘린다.
* 연속으로 맞히면 간격을 더 늘린다.

복습 간격 계산 자체는 AI에 맡기지 않는다.

정해진 알고리즘으로 계산한다.

AI는 다음 분야에 활용한다.

* 콘텐츠 생성
* 문맥 기반 표현 설명
* 난이도 조절

---

# 16. 암기 완료

일정 기준 이상 반복적으로 맞힌 표현은 `암기 완료` 상태로 표시할 수 있다.

완료된 표현도 완전히 삭제하지 않는다.

필요하면 장기 복습 대상으로 다시 등장할 수 있다.

암기 완료: 47개

복잡한 통계나 그래프는 MVP에서 제공하지 않는다.

### 게임 요소 (2026-10-02 개정, 백로그 035~041)

콘텐츠는 좋지만 학습 루프가 밋밋하다는 사용자 판단으로 게임 요소를 넣는다. 전부 기기 안에서 계산하며 AI 호출을 늘리지 않는다(3단계 "AI 콘텐츠 게임화"는 비용 증가로 보류).

* 퀴즈 콤보·점수: 연속 정답 콤보에 따라 문제당 10~30점, 정답/오답 햅틱·애니메이션, 결과 화면에 오늘 점수·최고 콤보.
* 표현 성장 단계: 연속 정답 0~4회를 씨앗·새싹·잎·꽃·열매로 표시(복습함, 퀴즈 피드백).
* 오늘의 미션 3개: 학습 1회 완료 / 정답률 80% 이상 / 새 표현 3개 저장. 달성 시 보너스 점수.
* 학습자 레벨·칭호: 누적 점수를 경험치로 보고 1~10레벨, 여행 스몰토크 칭호와 경험치 막대를 홈에 표시.
* 배지 10종, 스트릭 보호권(점수로 구매, 하루 빠지면 자동 사용), 주말 보스전(주 1회, 2배 점수).

성인 사용자에 맞게 유치한 보상 대신 "성장이 보이는" 표현을 쓴다. 다중 사용자 랭킹은 없다.

# 19. 복습함

대화 모드와 스토리 모드에서 저장한 표현을 하나의 목록에서 관리한다.

모드를 구분하지 않는다.

각 표현에서 보여줄 정보:

* 영어 표현
* 문맥상 의미
* 발음 재생
* 복습 상태

필요하면 최근 저장 순으로 볼 수 있다.

복습함의 현재 목록으로 연습 퀴즈를 바로 풀 수 있다(2026-10-08 개정, 백로그 052). 연습 결과는 표현의 복습 상태에만 반영하고 점수·스트릭·세션에는 넣지 않는다.

복잡한 검색·태그 기능은 MVP에서 구현하지 않는다. 약점 보기용 필터 세 개만 둔다(2026-10-02 개정, 백로그 044): 전체 / 자주 틀리는 표현 / 탭해서 뜻을 봤는데 아직 씨앗인 표현. 이를 위해 표현마다 탭 횟수를 기록한다.

# 24. 핵심 사용자 경험

이 앱의 가장 중요한 흐름은 다음 한 문장으로 정의한다.

> **재미있는 영어 콘텐츠를 읽고 듣는다 → 모르는 표현을 누른다 → 자동 저장된다 → 이후 새로운 콘텐츠와 퀴즈에서 자연스럽게 다시 만난다.**

새로운 기능을 추가할 때 이 흐름에 직접 도움이 되지 않는 기능은 우선순위를 낮춘다.

# 25. MVP 완료 기준

다음 흐름을 실제 Galaxy 기기에서 처음부터 끝까지 수행할 수 있으면 MVP가 완료된 것으로 본다.

1. 앱 최초 실행
2. 진단 테스트
3. 난이도 저장
4. Home 진입
5. Conversation 또는 Story 선택
6. AI 콘텐츠 생성
7. 전체/문장별 TTS
8. 표현 터치
9. 문맥 뜻 표시
10. 표현 자동 저장
11. Quiz 진행
12. Spaced Repetition 상태 갱신
13. 학습 결과 표시
14. 스트릭 갱신
15. 앱 종료
16. 앱 재실행
17. 이전 학습 데이터 유지
