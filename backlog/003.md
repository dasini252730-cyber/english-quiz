# 003 최초 레벨 진단

## 목적
최초 실행 사용자에게 짧은 진단을 제공하고, 결과를 이후 콘텐츠 생성의 초기 난이도로 사용한다.

## 작업 범위
- 첫 실행 여부를 002의 DataStore 상태로 판단한다. 미완료면 진단으로, 완료면 홈으로 이동한다.
- 요구사항에 정의된 세 형식(문장 의미, 자연스러운 표현 선택, 간단한 빈칸)을 섞은 고정 8문항의 진단 흐름을 제공한다. MVP 범위에서는 진단 자체에 AI 호출을 추가하지 않는다.
- 현재 문항과 전체 진행률(예: `3 / 8`)을 표시한다. 선택 후 다음 문항으로 이동하고, 마지막 응답을 제출하면 점수와 초기 난이도를 계산한다.
- 002가 제공하는 앱 상태 저장소를 통해 결과 난이도와 진단 완료 상태를 보존한다. 결과 저장이 성공한 뒤 홈으로 이동한다.
- 진단 이후 앱 재실행 시 진단을 다시 띄우지 않는다.

## 진단 기준 제안
- 문항은 각각 1점으로 채점해 총점 0–8점으로 계산한다.
- 점수 구간을 `0–3 beginner`, `4–6 intermediate`, `7–8 advanced`로 고정한다.
- 이 구간은 진단 초기값이며, 요구사항의 후속 학습 성과 기반 난이도 자동 조절은 별도 작업 범위로 둔다.

## 완료 기준
- DataStore에 진단 미완료 상태인 첫 실행에서 진단을 시작하고 8문항 진행률을 볼 수 있다.
- 세 문항 형식이 포함되고, 선택하면 다음 문항으로 진행하며 마지막 답변에서 점수 및 난이도를 일관되게 산출한다.
- 최종 결과와 완료 상태가 저장된 후 홈으로 이동하고, 앱을 재시작하면 진단을 건너뛴다.
- 저장 실패 때 완료 처리된 것처럼 홈에 진입하지 않고 사용자에게 재시도 가능한 오류를 보여준다.
- Android lint 및 `assembleDebug`가 통과한다.

## 관련 파일
- `요구사항/요구사항.md` — 최초 1회 진단, 예시 문항 형식, 진행률, 완료 후 홈 이동 및 이후 재진단 금지의 제품 요구사항.
- `app/src/main/AndroidManifest.xml` — 현재 런처 Activity 선언. 최초 진입 분기 연결 위치 확인.
- `app/src/main/kotlin/com/englishquiz/app/MainActivity.kt` — Compose 컨텐츠 시작점. 진단 완료 여부에 따른 시작 화면 위임을 연결.
- `app/src/main/kotlin/com/englishquiz/app/ui/EnglishQuizApp.kt` — 현재 초기 화면만 렌더링하는 Compose 진입 화면. 진단/홈 화면 상태 흐름의 연결 지점.
- `app/build.gradle.kts` — Compose 및 앱 의존성. Navigation 라이브러리가 필요하면 기존 단순 구조와 비교해 최소 의존성으로 추가.
- 002에서 추가할 DataStore 상태 모델/저장소 — 진단 완료 여부와 초기 난이도 저장·복원. 실제 경로와 API는 002 구현에 맞춤.
- 진단 화면, 문항 모델/문항 데이터, 결과 계산을 위한 신규 Kotlin 파일 — 화면 UI와 고정 문항·점수 계산을 분리해 파일별 줄 제한을 지킴.

## 실행 순서
1. 002의 DataStore 인터페이스와 상태 모델이 준비되었는지 확인하고, 진단 완료 여부 및 레벨의 읽기/저장 API를 합의한다.
2. 세 문항 유형을 포함한 고정 8문항 모델과 답안 검증·점수 구간 계산을 구현하고, 저장이 완료되기 전에 진단 완료 상태를 노출하지 않게 한다.
3. 진행률, 선택지, 선택 후 다음 문항, 완료 결과를 Compose 화면으로 구현한다. 재구성에도 응답/현재 인덱스가 유지되도록 상태를 관리한다.
4. 앱 시작 시 DataStore 상태로 진단 또는 홈을 결정하고, 마지막 문제 완료 후 저장 결과에 따라 홈으로 이동하도록 연결한다.
5. 테스트 가능한 순수 점수 계산 로직을 검증한 다음 Android lint와 `assembleDebug`를 실행한다. 저장 재시작 흐름은 가능한 Android 테스트 환경에서 확인하고 환경 제한은 기록한다.

## 현재 상태
- `Assessment.questions`에 세 문항 형식을 갖춘 8개 고정 문항과 1점 채점 로직을 두고, 점수 구간을 초급(0–3), 중급(4–6), 고급(7–8)으로 매핑한다. 저장 난이도 값은 각각 1, 2, 3이다.
- `EnglishQuizApp`은 002의 `AppSettingsRepository.settings`로 첫 진입을 판단하고, 미완료일 때 진단, 완료일 때 홈 placeholder를 표시한다. 설정 읽기 오류는 진단 미완료 기본값으로 취급하지 않고 오류·재시도 화면을 표시한다.
- `AssessmentScreen`은 현재 문항/답변을 재구성 및 회전 후에도 보존하고, 빠른 연속 탭에서 오래된 선택 콜백이 다음 문항을 넘기지 않게 방어한다. 마지막 답변의 난이도와 완료 상태를 DataStore에 저장한 뒤 저장소 Flow가 완료를 알리면 홈으로 이동한다. 저장 실패 시 답변을 유지하고 다시 시도할 수 있다.
- `AssessmentTest`, `AppSettingsRepositoryTest`, `AssessmentFlowTest`가 문항 형식/개수와 점수 경계, 읽기 실패 전파, 첫 실행의 진행률, 저장 중 홈 미진입, 저장 실패 재시도, 저장된 난이도, 저장소 파일 재개방 후 진단 생략을 검증한다.
