# 016 Android 계측 테스트 환경 복구

## 목적
에뮬레이터/계측 실행 환경을 정상화해 Room의 실제 파일 저장·재개방과 Compose UI 실행을 검증한다. 이 항목은 확인된 test infrastructure 차단 요인을 다룬다.

## 확인된 증거
- 순수 assessment 점수 테스트와 DataStore 오류 테스트는 통과했다.
- Room 계측 테스트는 SQLite 호출 전에 디렉터리 생성 단계에서 실패했다. test context의 `/data/user/0/com.englishquiz.app.test`가 없고 쓰기 불가해 `mkdirs()`도 실패했다. Room fixture를 설치된 target app context와 고유 파일명으로 옮겼다.
- non-wipe reboot 뒤 AVD가 다시 online/boot complete 됐고 target app dataDir가 생성됐으며 MainActivity 실행에 성공했다.
- 후속 suite에서 test APK Activity host가 다른 process로 resolve돼 Compose assertion 전에 실패했다. test host를 target debug APK의 ComponentActivity로 옮겼다.
- migration test가 schema JSON을 test assets에서 찾지 못해 실패했다. `app/schemas`를 androidTest assets에 추가했다.
- reviewer는 최초 test context dataDir 부재를 infrastructure 문제로 판정했다. 후속 Activity host/schema 설정 문제는 수정 후 재검증해야 한다. 현재 Room/UI suite는 통과하지 않았다.

## 작업 범위
- 기존 emulator 데이터를 지우지 않고 AVD를 정상 부팅·실행한다.
- 설치된 target app sandbox가 만들어지고 쓰기 가능한지 확인한다.
- `createComposeRule` host를 debug target APK에서 실행하고 화면 assertion까지 진행한다.
- Room test는 production DB가 아닌 고유 DB를 사용해 close/reopen 뒤 세션·표현·복습 상태와 due query를 확인한다.
- migration test가 v1 및 v2 schema assets를 읽어 기존 기록을 보존하는지 검증한다.
- 실기기 검증이 가능한 경우에도 별도 원래 task 기준을 확인하고 기록한다.

## 완료 기준
- Activity host 및 Compose 테스트가 화면 assertion까지 실행된다.
- Room 테스트가 정상 sandbox의 파일 DB에서 저장, close/reopen, 재조회까지 통과한다.
- MigrationTestHelper가 v1 DB를 v2로 옮기고 schema 검증을 통과한다.
- `lint`, `assembleDebug`, `connectedDebugAndroidTest`가 통과한다.
- 원래 기능 task는 사용자 지시에 따라 별도 실기기 검증 근거 확보 전까지 `done` 처리하지 않는다.

- `011`: 복습 상태 Room 저장 및 due query
