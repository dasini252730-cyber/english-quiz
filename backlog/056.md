# 056 퀴즈 모드별 복습 기록 규칙 확정 (일반만 일정 변경, 보스·연습은 기록만)

## 목적
2026-10-10 사용자 지침. 일반 지문 퀴즈만 성장 단계·복습 일정을 바꾼다. 주말 보스전은 2배 점수와 도전 기록만, 복습함 연습은 약점 확인만. 두 모드 모두 정답·오답을 별도 답변 기록(표현, 모드, 정오답, 힌트 사용, 시각)에 남기되 정식 복습 단계·날짜는 건드리지 않는다. 되묻기 정답은 정식 정답으로 계산하지 않는 현재 규칙 유지. '자주 틀리는' 필터는 이 기록도 함께 본다.

## 작업 범위

1. **Room 엔티티 및 마이그레이션 (8→9)**
   - `quiz_answers` 테이블: expressionId (FK), mode (문자열), isCorrect, hintUsed, answeredAtEpochMillis
   - 인덱스: (expressionId, mode), mode 별 쿼리 성능 최적화
   - 데이터 손실 없음 (새 테이블 추가만)

2. **답변 기록 분기 처리**
   - 일반(daily): 기존 recordAnswer 동작 유지 (단계·일정 변경) + quiz_answers 로깅
   - 보스(boss): quiz_answers만 로깅, 단계·일정 변경 금지
   - 연습(practice): 오답만 quiz_answers 로깅, 정답은 기록 금지

3. **약점 필터 통합**
   - WeakSpotPolicy.apply() 내부에서 DAO 쿼리 불가 → 리포지토리 계층에서 데이터 조회 후 필터링
   - "자주 틀리는" = incorrectCount ≥ 1 OR 오답 로그 exists (모드 무관)
   - 정렬: 오답 로그 개수 내림차순, 그 다음 incorrectCount 내림차순

4. **호출 경로**
   - QuizRoute.record() → repository.recordQuizAnswer(expressionId, mode, isCorrect, hintUsed, now) 추가 호출
   - 모드 매핑: daily=todayContent.mode.wireValue (conversation/story), boss="boss", practice="practice"
   - BossRoute와 ReviewQuizRoute는 QuizRoute에 practice/pointsMultiplier 플래그로 전달 (이미 구현됨)

## 구현 메모 (2026-10-10)
- `quiz_answers` 테이블(마이그레이션 8→9): expressionId, mode(daily/boss/practice), isCorrect, hintUsed, answeredAt. `QuizRoute.record()`가 모든 모드에서 남기고, `QuizMode.DAILY`일 때만 `recordAnswer`(단계·일정)를 호출한다. 되묻기·지문 질문은 기록하지 않는다.
- 연습은 정답도 기록한다(사용자 지침: 정답률 계산용). 보스전도 같다. 둘 다 행의 단계·일정·숙달은 그대로.
- "자주 틀리는" = 행의 `incorrectCount`(일일 퀴즈 오답) + 기록 중 보스·연습 오답 수. 일일 오답은 행에 이미 있으므로 기록 쪽 집계에서 `mode <> 'daily'`로 제외한다(리뷰 반영).
- 일일 퀴즈의 일정 변경과 기록은 한 트랜잭션: 일정 쓰기가 실패해 재시도해도 기록이 두 줄 남지 않는다(리뷰 반영).
- 힌트 사용 여부(`hintUsed`)는 여기서 함께 기록한다(058의 기록 부분). 승급 차등은 데이터를 본 뒤 결정.
