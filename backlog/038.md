# 038 학습자 레벨·칭호·경험치 막대

## 목적
세션 점수+미션 보너스 합계를 경험치로 보고 학습자 레벨(1~10)과 여행 스몰토크 칭호(공항 도착→스몰토크 마스터)를 홈에 경험치 막대와 함께 표시. 결과 화면에 획득 경험치와 레벨업 안내.

## 작업 범위
새로운 도메인 정책 `LearnerLevelPolicy`로 모든 누적 세션의 점수를 경험치로 계산하여 1~10 레벨과 여행 스몰토크 칭호 결정.
홈 화면에 새로운 `HomeLevelCard` UI로 현재 레벨, 칭호, 경험치 막대 표시.
결과 화면에 이번 세션 획득 경험치와 레벨업 메시지 추가.

## 완료 기준
- `domain/game/LearnerLevelPolicy.kt` 구현: XP 누적 계산(모든 세션 score 합) 및 레벨(1~10) 매핑, 칭호 결정
- `ui/HomeLevelCard.kt` 구현: 현재 레벨, 칭호, 경험치 막대 UI
- `HomeRoute.kt` 수정: `repository.findLearningSessions(todayIso())` 및 전체 세션 조회 추가, `HomeSummary`에 `learnerLevel`, `totalXp`, `xpThisSession` 필드 추가
- `HomeScreen.kt` 수정: `HomeLevelCard` 렌더링 추가
- `ResultScreen.kt` 수정: 이번 세션 획득 XP와 레벨업 여부 표시
- `LearningSessionSummary.kt` 수정: `xpEarned` 필드 추가 (score 기반)
- 관련 테스트 수정: `HomeScreenTest.kt`, `ResultScreenTest.kt`

## 구현 순서

1. **LearnerLevelPolicy 작성** (`domain/game/LearnerLevelPolicy.kt`)
   - Data class `LearnerLevel(level: Int, title: String, totalXp: Int, xpNextLevel: Int)`
   - Fun `calculateLevel(totalXp: Int): LearnerLevel` — XP를 누적점수로 보고 1~10 레벨 계산
   - 레벨별 XP 임계값 정의: 레벨 1-10, 각 레벨당 필요 경험치 (예: 100*레벨 누적)
   - 칭호 맵: 1=공항 도착, 2=탑승권 확인, 3=짐 확인, 4=체크인, 5=보안검사, 6=면세점, 7=탑승, 8=이착륙, 9=짐 찾기, 10=스몰토크 마스터
   - `fun xpEarnedThisSession(score: Int, missionBonus: Int = 0): Int` — 이번 세션 획득 XP (점수 + 미션)

2. **HomeLevelCard 작성** (`ui/HomeLevelCard.kt`)
   - Composable `HomeLevelCard(level: LearnerLevel, xpEarnedThisSession: Int?)` — 현재 레벨, 칭호, 경험치 막대 표시
   - 진행률 표시: (현재 XP - 현재 레벨 시작XP) / (다음 레벨 필요XP - 현재 레벨 시작XP)
   - 레벨업 시 축하 메시지 (선택사항)

3. **HomeRoute 수정** (`ui/HomeRoute.kt`)
   - `LearningHomeSummary` → `produceState`에서 전체 세션 조회 추가: `repository.listLearningSessions()` 또는 필요 시 새 메서드
   - `LearnerLevelPolicy.calculateLevel(totalXp)` 호출하여 레벨 계산
   - `HomeSummary` 생성 시 `learnerLevel`, `totalXp` 필드 추가

4. **HomeSummary 확장** (`ui/HomeScreen.kt`)
   - Data class `HomeSummary`에 `learnerLevel: LearnerLevel?`, `totalXp: Int = 0` 필드 추가

## 구현 메모 (2026-10-02)
- `domain/game/LearnerLevelPolicy.kt`: 경험치 = Σ세션 score + Σ일별 미션 보너스. 레벨 1→2는 300점, 이후 150점씩 증가(최대 10레벨, 총 8,775점 ≈ 5주). 칭호 10개(공항 도착 … 스몰토크 마스터).
- 백로그 초안의 `xpEarned`/`HomeSummary.totalXp` 대신 **경험치를 Room 세션에서 매번 재파생**한다(`GameStatsPolicy`). 저장값이 하나라 이중 집계·불일치가 불가능. 홈/결과가 같은 함수를 쓴다. 카드는 `HomeLevelCard.kt`/`HomeMissionCard.kt` 대신 `ui/HomeGameCards.kt` 한 파일.
- 홈: `HomeLevelCard`(Lv·칭호·누적 점수·막대·다음 레벨까지). 결과: `ResultGamePanel`(+N 경험치, 레벨 업! 칩, 막대). 레벨업 판정은 이 세션 행을 제외한 전/후 비교(`ui/result/ResultGame.kt`), 프로세스 사망 후 재생해도 같은 값.
