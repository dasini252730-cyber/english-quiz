# 055 표현 학습 상태 4단계 분리 (새 표현 대기열 · 첫 복습 대기 · 복습 예정 · 숙달)

## 목적
2026-10-10 사용자 지침. 저장됨 ≠ 첫 학습 완료 ≠ 복습 시점 도래를 코드로 명시한다. ① 새 표현 대기열(카드도 못 본 표현, 하루 5개만 첫 학습 투입) ② 첫 학습 완료·첫 복습 대기(카드 본 표현, 다음 날 첫 채점) ③ 복습 예정(날짜 도래, 가장 밀린 것부터) ④ 숙달(열매, 30일 주기 유지). 지문에서 12개가 등록되면 그날 카드는 5개, 나머지는 대기열에 남아 차례로. 학습 카드 버튼은 '뜻 확인 완료' 하나로 바꾼다(자기평가로 승급하지 않음).

## 작업 범위

### 도메인 모델: ExpressionState 추가
`SavedExpressionEntity` + 현재 시각에서 파생되는 학습 상태를 명시화.

**4단계 상태**:
- NEW: 카드도 못 본 표현 (lastReviewedAtEpochMillis == null)
- FIRST_REVIEW_PENDING: 카드 본 후 첫 복습 대기 (내일 첫 채점)
- DUE: 복습 예정 (nextReviewAtEpochMillis <= now && !isMastered)
- SCHEDULED: 예정됨 (nextReviewAtEpochMillis > now && !isMastered)
- MASTERED: 숙달 (isMastered == true)

### 학습 카드 UI 변경
"알아요" + "모르겠어요, 내일 다시" (두 버튼) → "뜻 확인 완료" (단일 버튼)
- 동작 동일: markSeen() → next()로 진행
- 내일 첫 복습 대기 상태로 전환
