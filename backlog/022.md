# 022 같은 날 재진입의 0문항 세션이 난이도 평균을 끌어내림

## 발견 경위
021(오늘의 콘텐츠 보관) 후속 리뷰(code-critic, 2026-09-26)에서 나왔다. 021 이 캐시 재진입의 이중 복습을 막기 위해
퀴즈 후보를 due 로만 한정하자, 같은 날 같은 모드에 다시 들어가면 due 가 비어 **0문항 퀴즈 → 결과 화면 →
`learning_sessions` 에 0문항·0저장 세션 행**이 확정적으로 남게 됐다. 빈 퀴즈 자체는 010 때부터 있던 형태지만
021 이 이를 "재진입마다 반드시 발생"으로 바꿨다.

## 영향
- `DifficultyPolicy` 는 정답률 쪽은 `MIN_SESSIONS_WITH_QUIZ` 로 막지만, `averageSaved` 는 `window.size` 로
  나눈다. 0저장 세션이 평균을 낮춰 `averageSaved <= EASY_SAVE_COUNT` 를 만족시키면 실질 근거가 1세션뿐인데도
  난이도가 올라갈 수 있다.
- 스트릭은 날짜 단위라 영향 없음. 결과 화면 숫자(0/0)도 사실이라 표시 자체는 문제 아님.

## 관련 파일
- `app/src/main/kotlin/com/englishquiz/app/domain/difficulty/DifficultyPolicy.kt` — 창 계산과 `averageSaved`
- `app/src/main/kotlin/com/englishquiz/app/ui/result/ResultRoute.kt` — 세션 기록 지점
- `app/src/main/kotlin/com/englishquiz/app/ui/session/LearningSessionRoute.kt` — 재진입 경로

## 선택지
1. `DifficultyPolicy` 가 0문항 세션을 창에서 통째로 제외한다(정답률뿐 아니라 저장 수 평균에서도). 가장 국소적.
2. 재진입 세션(0문항·0저장)은 아예 기록하지 않는다. 통계는 깨끗해지지만 "오늘 학습 완료" 화면과의 정합을
   따져야 한다.

## 완료 기준
- 같은 날 재진입을 여러 번 해도 난이도 판정이 1회차 세션만으로 이뤄진 것과 같다.
- `DifficultyPolicyTest`(있으면) 또는 새 단위 테스트가 0문항 세션 포함 창을 고정한다.
- 기존 013 테스트가 그대로 통과한다.
