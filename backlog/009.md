# 009 복습함 목록

## 목적
모드와 무관하게 사용자가 자동 저장된 표현과 복습 상태를 다시 확인한다.

## 작업 범위
- 저장 표현을 최근 저장 순으로 표시한다.
- 영어 표현, 문맥상 의미, 발음 재생, 복습 상태를 보여준다.
- 빈 목록 상태와 긴 목록 스크롤을 처리한다.
- 검색/필터/태그는 구현하지 않는다.

## 완료 기준
- 콘텐츠에서 저장한 표현이 복습함에 나타난다.
- 표현 발음 재생 및 상태 정보를 확인할 수 있다.
- 데이터가 없는 경우 안내 문구가 표시된다.

## 선행 작업
002, 004, 008

## 2026-09-20 준비 구현 및 검증
- `ui/review/ReviewRoute.kt`, `ReviewScreen.kt`를 추가하고 `EnglishQuizApp.kt`의 홈 복습함 버튼에 연결했다. DAO의 최근 저장순 목록을 사용해 표현, 문맥 뜻, 복습 상태와 발음 재생을 제공한다.
- 로딩, 빈 목록, 조회 오류 및 재시도를 처리하고 화면 이탈/백그라운드에서 음성을 중단한다. 홈의 표현 조회도 홈에서만 수행하고 오류를 처리하도록 보완했다.
- code-critic 리뷰에서 확인된 코드 결함은 없었다. 복습함 전용 UI 테스트와 저장 직후 반영, 재실행 유지, 긴 목록, 음성 재생의 실기기 증거는 남아 있다.
- `lint`, `assembleDebug`, `testDebugUnitTest`, `compileDebugAndroidTestKotlin` 통과. 연결된 adb 기기가 없어 UI/음성 계측 실행은 하지 않았다.
- 선행 002/004/008 미완료이므로 waiting을 유지한다. 이 기록은 구현 준비이며 완료 판정이 아니다. 실기기 검증 대상은 Galaxy S26 한 대다.

## 관련 파일

- `app/src/main/kotlin/com/englishquiz/app/data/repository/LearningRepository.kt` — 저장 표현 관찰 Flow와 복습 진행 상태 API를 제공하므로 목록 화면의 데이터 진입점이다.
- `app/src/main/kotlin/com/englishquiz/app/data/local/LearningEntities.kt` — `SavedExpressionEntity`에 표현, 문맥상 의미, 최초 저장일, 최근/다음 복습일, 정답·오답 횟수와 암기 완료 상태가 정의되어 있다.
- `app/src/main/kotlin/com/englishquiz/app/data/local/LearningDao.kt` — 최초 저장일 내림차순 목록 조회와 저장 표현 영속화를 제공한다.
- `app/src/main/kotlin/com/englishquiz/app/ui/reader/ReaderSpeech.kt` — Reader에서 사용하는 Android 음성 재생 구현이며 복습함의 표현 발음 재생에 재사용 여부를 검토할 대상이다.
- `app/src/main/kotlin/com/englishquiz/app/ui/EnglishQuizApp.kt` — 홈의 복습함 진입 callback과 앱 화면 전환을 연결하는 호스트다.
- `app/src/main/kotlin/com/englishquiz/app/ui/HomeScreen.kt` — 이미 `onReviewClick`을 노출하므로 복습함 목적지 연결 기준이 된다.
- `app/src/androidTest/kotlin/com/englishquiz/app/data/repository/LearningRepositoryTest.kt` — 저장 표현 및 Room 연동 검증 패턴을 참고할 수 있다.
- `app/src/androidTest/kotlin/com/englishquiz/app/data/repository/ReviewProgressPersistenceTest.kt` — 복습 상태 저장·재개방 검증을 참고할 수 있다.

## 구현 순서

1. 선행 작업 002, 004, 008의 저장·앱 진입·문맥 의미 저장 완료 여부를 확인하고 `LearningRepository.observeSavedExpressions()`의 상태 수집 경계를 정한다.
2. 저장 표현을 최근 저장 순으로 수집해 영어 표현, 문맥상 의미, 복습 상태(다음 복습일/암기 완료 등)를 표시하는 복습함 화면을 구현한다.
3. 기존 음성 재생 수명주기 처리를 재사용해 항목별 발음 재생과 실패 피드백을 연결하고, 빈 목록 안내 및 긴 목록 스크롤을 제공한다.
4. `EnglishQuizApp`의 복습함 목적지와 뒤로가기를 연결한 뒤 저장·복습 상태 변경이 화면에 다시 반영되는지 검증한다.
5. 목록/빈 상태/발음·상태 표시와 Room 재시작 보존을 테스트하고 Android lint 및 `assembleDebug`를 실행한다.

## 2026-09-21 복습함 테스트 추가

009 문서가 남겨 둔 "복습함 전용 UI 테스트" 공백을 채웠다.

- `app/src/androidTest/.../ui/ReviewScreenTest.kt` — 표현·문맥 뜻·복습 상태 칩 표시, 발음 재생이 해당 표현만 재생하는지, 음성 미준비 시 비활성, 빈 목록 안내, 조회 실패 재시도, 뒤로가기.
- `app/src/androidTest/.../ui/ReviewRouteTest.kt` — Room 에 저장한 표현이 목록에 나타나는지, DB 를 닫았다 다시 열어도 남아 있는지, 빈 저장소 안내.

구현 쪽도 하나 정리했다. 칩과 상태 줄이 둘 다 "암기 완료"를 보여 주어 같은 말을 두 번 했다. `reviewStatus()` 를 `nextReviewLabel()` 로 바꿔 상태 이름은 칩만 담당하고, 아래 줄은 예정된 복습 날짜가 있을 때만 그것만 보여 준다. 암기 완료 표현은 예정일이 없으므로 줄이 사라진다.

`compileDebugAndroidTestKotlin`, `lint`, `testDebugUnitTest`, `assembleDebug` 통과. 계측 실행은 기기가 없어 하지 못했다. 선행 004/008 도 미완료이므로 `waiting` 을 유지한다.
