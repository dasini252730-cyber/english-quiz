# 036 표현 성장 단계(씨앗→열매) 표시

## 목적
저장 표현의 연속 정답 0~4회를 씨앗·새싹·잎·꽃·열매 5단계로 보여준다. 복습함 칩과 퀴즈 피드백('새싹→잎으로 자랐어요', 오답 시 씨앗으로). 저장 구조 변경 없음.

## 작업 범위
- GrowthStage 스스로 선택하여 UI에 적용
- QuizQuestion에 growthBefore 필드 추가
- ReviewScreen의 reviewChip에서 성장 단계 표시
- 퀴즈 피드백에서 단계 변화 표시 (예: "새싹 → 잎으로 자랐어요")
- 오답 시 "씨앗으로 초기화되었어요" 표시

## 완료 기준
- ReviewScreen의 reviewChip이 GrowthStage를 표시
- QuizQuestion 생성 시 growthBefore(consecutiveCorrectCount) 캡처
- QuizFeedback에서 정답 시 "단계 → 단계로 자랐어요", 오답 시 "씨앗으로 초기화됨" 표시
- 저장 구조 변경 없음(기존 consecutiveCorrectCount 활용)
- ReviewScreenTest, QuizBuilderTest, QuizScreenTest 등 기존 테스트 수정

## 구현 순서

1. **QuizModels.kt:** QuizQuestion에 `growthBefore: Int = 0` 필드 추가
2. **QuizBuilder.kt:** buildQuestion에서 expression.consecutiveCorrectCount를 growthBefore로 전달
3. **ReviewScreen.kt:** reviewChip 함수 수정 - consecutiveCorrectCount와 isMastered로 GrowthStage.of() 호출, 결과의 title 반환
4. **QuizScreen.kt:** QuizFeedback에 성장 단계 변화 메시지 추가
   - 정답: "단계변화→단계로 자랐어요" (growthBefore와 현재 진행률 비교, 또는 recordAnswer 결과 활용)
   - 오답: "씨앗으로 초기화되었어요" (consecutiveCorrectCount → 0)
5. **테스트 업데이트:** QuizQuestion 생성 코드의 growthBefore 파라미터 설정 (기본값이므로 생략 가능하나, 명확성 위해 표시)

## 구현 메모 (2026-10-02)
- `domain/game/GrowthStage.kt`: 씨앗·새싹·잎·꽃·열매 = 연속 정답 0/1/2/3/암기완료. `title` = "이모지 라벨".
- `QuizQuestion.growthBefore`(빌드 시점 단계) → 답 기록 후 `GrowthChange(before, after)`를 피드백 카드에 "sketchy: 🌱 새싹 → 🌿 잎으로 자랐어요" / "🌰 씨앗으로 돌아갔어요"로 표시. 조사는 받침에 따라 (으)로 선택(`directionParticle`, "열매로").
- 복습함 칩은 성장 단계로 교체. 열매는 기존 문구 "암기 완료"를 유지(🍎 암기 완료). "새로 저장"과 "학습 중(연속 0)"은 둘 다 씨앗으로 보인다 — 단계가 곧 상태라는 설계로 수용.
- 테스트: `GrowthStageTest`, `ReviewScreenTest`(씨앗/새싹/암기 완료 칩), `QuizScreenTest`(성장 문구).
