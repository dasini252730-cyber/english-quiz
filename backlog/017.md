# 017 디자인 시스템 적용 (몽글잉글)

## 목적
사용자가 제공한 Design 캔버스 시안(`영어 단어 앱 UI`, 11개 아트보드)을 Compose 디자인 토큰과 공용 컴포넌트로 옮기고, 기존 모든 화면에 적용한다. 기능 변경이 아니라 시각 언어를 통일하는 작업이다.

- 아트보드: 02 레벨 진단, 03 홈, 04 콘텐츠 생성/생성 오류, 05 대화 학습, 06 스토리 학습, 07 표현 의미 오버레이, 08 퀴즈(객관식·빈칸/정답), 09 학습 결과, 10 복습함

## 확정된 구현 결정 (2026-09-21, 메인)
- **폰트**: 제목용 Jua 는 `app/src/main/res/font/jua_regular.ttf`(Google Fonts, SIL OFL, 2.1 MB)로 번들한다. Downloadable Fonts 는 `com_google_android_gms_fonts_certs` 인증서 배열과 Play 서비스·네트워크가 필요해 첫 실행 품질이 흔들리므로 쓰지 않는다. 본문 Noto Sans KR 은 번들하지 않는다. 세 굵기를 넣으면 APK 가 16 MB 가까이 늘고, 대상 기기의 시스템 산세리프가 이미 한국어를 잘 그린다. 스토리 본문만 `FontFamily.Serif`(시안의 Lora 대체)를 쓴다.
- **버튼 입체감**: 시안의 `border-bottom: 4~6px` 는 어두운 면을 뒤에 깔고 그 위에 밝은 면을 올려 표현한다. 누르면 면이 그림자 두께만큼 내려간다.
- **semantics**: Material `Button`/`OutlinedButton` 을 직접 만든 `Box + clickable` 로 바꿨다. `Modifier.clickable` 자체가 이미 `mergeDescendants` 로 병합하고 `Role` 과 `disabled()` 를 심으므로 추가 `semantics` 는 필요 없다. 기존 계측 테스트의 `onNodeWithText(...).performClick()` 과 `assertIsNotEnabled()` 는 그대로 성립한다.
- **아이콘**: 아이콘 아티팩트를 추가하지 않고 시안의 SVG path 문자열을 `PathParser` 로 그대로 `ImageVector` 로 만든다. 검정으로 그리고 `Icon(tint = …)` 이 색을 입힌다.
- **표현 마커**: AI 가 표시한 `ContentExpression` 토큰만 노란 배경 + 아래 밑줄로 그린다. 나머지 토큰은 평범한 본문이다. 탭 동작과 `tokenize` 는 그대로다.
- **대화 말풍선 좌우**: 화자 이름이 `Me`/`나` 면 오른쪽, 없으면 두 번째로 등장한 화자를 오른쪽에 둔다. 한 명뿐인 콘텐츠는 전부 왼쪽이다.
- **표현 의미 오버레이**: 시안대로 바텀시트 모양이고, 모달성은 `Dialog(usePlatformDefaultWidth = false)` 로 유지한다. Reader 위에 떠 있어 스크롤 위치를 건드리지 않고 뒤로가기 dismiss 도 그대로다. 다만 콘텐츠가 창 전체를 덮으면 플랫폼의 바깥 탭 dismiss 가 동작하지 않으므로, 스크림 Box 가 직접 `onDismiss` 를 호출하고 시트는 `detectTapGestures` 로 탭을 삼킨다. 스크림에는 시안의 `aria-label="닫기"` 에 해당하는 contentDescription `표현 뜻 닫기` 를 준다.
- **보기 버튼 높이**: 보기 텍스트는 AI 가 만든 뜻 문자열이라 길이 상한이 없다. 고정 60dp 대신 `heightIn(min = 60.dp)` 로 두어 여러 줄이 잘리지 않게 한다.
- **아이콘 버튼 터치 타깃**: 시안은 44dp 영역 안에 32dp/28dp 원을 그린다. `MongleIconButton` 은 터치 타깃(`size`, 최소 44dp)과 그려지는 원(`circleSize`)을 분리한다.

## 2026-09-21 적대적 리뷰 반영
- **바깥 탭 dismiss 미동작(회귀)**: `usePlatformDefaultWidth = false` + 전체 화면 콘텐츠라 플랫폼의 `dismissOnClickOutside` 가 발화하지 않았다. 스크림 Box 에 dismiss 클릭을, 시트에 탭 소비를 붙여 고쳤다. `ReaderScreenTest.tappingOutsideTheSheetClosesTheMeaningOverlay` 로 덮었다.
- **보기 텍스트 잘림(회귀)**: `MongleOptionButton` 이 고정 60dp + clip 이라 두세 줄짜리 뜻이 잘렸다. `heightIn(min = 60.dp)` 으로 바꿨다.
- **터치 타깃**: 대화 40dp / 스토리 36dp / 복습함 40dp 재생 버튼이 44dp 미만이었다. `circleSize` 를 도입해 타깃은 44dp 로 두고 원만 작게 그린다.
- **대비**: 복습함 상태 줄의 `InkFaded`(흰 면 위 약 3.5:1)를 `InkMuted`(약 6.9:1)로 바꿨다.
- **중복 제거**: `clickable` 뒤의 불필요한 `semantics(mergeDescendants = true)` 5곳과 쓰이지 않던 `OptionTone.Selected` 를 없앴다.
- **뷰포트 위험**: 퀴즈 화면이 시안대로 높아져 짧은 에뮬레이터에서 "다음 문제"가 화면 밖으로 밀릴 수 있다. `QuizRouteTest` / `QuizScreenTest` 가 단언·탭 전에 `performScrollTo()` 하도록 고쳤다.
- 남겨둔 지적: `MongleTopBar` 의 back contentDescription 기본값 `홈으로` 는 Reader 에서도 실제로 홈으로 나가므로(`LearningSessionRoute.onExit` → `goHome`) 그대로 둔다. `MongleColor` 의 미사용 토큰(`HighlightActive`, `BlueBorder`, `GreenBorder`)은 시안 팔레트 전체를 담는다는 파일 목적에 맞아 남긴다.
