# 012 학습 결과와 스트릭

## 목적
하루 학습이 끝났음을 기록하고 핵심 성과를 간단히 보여준다.

## 작업 범위
- 오늘 학습한 표현 수, 신규 저장 수, 퀴즈 정답률, 암기 완료 수를 산출한다.
- 학습 완료 날짜를 저장하고 연속 학습 스트릭을 계산한다.
- 결과 화면에서 완료를 선택하면 홈으로 돌아간다.
- 앱 재실행과 날짜 변경 뒤에도 스트릭이 일관되게 보이도록 한다.

## 완료 기준
- 결과 수치가 해당 학습 세션 기록과 일치한다.
- 하루 한 번의 학습 완료가 스트릭에 반영된다.
- 불필요한 그래프/복잡한 통계는 추가하지 않는다.

## 확정된 구현 결정 (2026-09-20, 메인)
- `learningDate`는 기존 코드와 같이 기기 로컬 시간대의 `yyyy-MM-dd` 문자열을 쓴다.
- 스트릭은 **로컬 자정** 기준 연속 일수다. 같은 날짜에 세션이 여러 번 기록돼도 1일로 센다.
- 오늘 기록이 있으면 오늘까지, 없고 어제 기록이 있으면 어제까지를 연속 구간으로 본다. 어제·오늘 모두 없으면 0일이다. 시계 되돌림 등으로 미래 날짜가 섞여 있으면 기준일 이후 날짜는 무시한다.
- 스키마 변경은 하지 않는다. `learning_sessions.learningDate`로 일 단위 묶음이 가능하다. 메인이 `LearningDao.listLearningDates()`(DISTINCT, 내림차순)와 `LearningRepository.listLearningDates()` / `findLearningSessions(date)`를 추가해 뒀다.
- 스트릭 계산은 순수 Kotlin 도메인 함수로 두고 기준 날짜를 외부 입력으로 받는다. AI를 쓰지 않는다(요구사항 22절).
- 결과 화면 수치는 요구사항 SCREEN-09에 맞춰 정답률, 새로 배운 표현 수, 복습한 표현 수, 스트릭만 보여 준다. 그래프나 추가 통계는 넣지 않는다.
