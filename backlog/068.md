# 068 중국어 2/6: Room v12 언어 분리 마이그레이션과 언어별 조회

## 목적
daily_content PK에 language, saved_expressions language·pinyin·유니크(language,normalizedExpression), seasons/season_episodes/learning_sessions language, DAO·리포지토리·SeasonCoordinator·프리페치 언어 조건, 11→12 마이그레이션 테스트. 에픽 066의 B절.

## 작업 범위
- `LearningEntities.kt`/`SeasonDao.kt`: `language` 열(기본 'en'), `saved_expressions.pinyin`, `daily_content` PK `(language, learningDate, mode)`, `seasons` 유니크 `(language, number)`.
- `MIGRATION_11_12`: ADD COLUMN들, 인덱스 교체, `daily_content` 재생성 복사. 스키마 12.json 내보냄.
- `LearningDao`: 표현·지문·시즌 조회에 언어 조건. 세션 전체 조회(`listAllSessions`, `listLearningDates`)와 `listAllSavedExpressions`는 전체(스트릭·게임 공유).
- `LearningRepository`(+ `LearningRepositoryAnswers.kt` 분리): 모든 표현 함수에 `language`; `normalizeExpression(language, text)`는 zh에서 공백·문장부호 제거.
- `LearningRepositoryContent`: `findDailyContent(language, …)`, `findPreviousSummary(language, …)`, `listLibrary(language)`, `listRecentSessionSummaries(mode, limit, language)`.
- `SeasonCoordinator`: 모든 공개 함수에 `language`, 시즌·회차 행에 언어 기록. `ContentPrefetcher`: 선택 언어만. `DailyContent.todaysContent(…, language, …)`.
- `AiLearningModels`: `ContentGenerationRequest.language`, `MeaningRequest.language`, `SeasonRequest.language`, `LearningContent.language`(마지막 파라미터), `ContentSegment/ContentExpression/GlossaryEntry/ContextualMeaning.pinyin`. `AiLearningResponses`는 `pinyin`·`language`를 읽고 `AiLearningResponseJson.kt`(분리)가 쓴다.
- UI 호출부 전부에 언어 전달(퀴즈·복습함·라이브러리·보스·결과·리더 뜻 저장).

## 완료 기준
- 11→12 마이그레이션 후 기존 영어 행이 그대로 읽히고(언어 'en'), 같은 날·같은 모드의 중국어 지문이 영어 지문과 공존한다.
- 같은 문자열을 두 언어로 저장하면 두 행. 복습 큐·보스 후보·라이브러리는 선택 언어만 반환.
- 계측 테스트(마이그레이션·리포지토리·시즌·설정·프리페치) 컴파일 및 기기 실행.

## 리뷰 반영 (2026-10-18, code-critic)
- **[치명] 생성된 중국어 지문이 'en'으로 저장되던 결함**: 서버는 응답에 language를 돌려주지 않으므로 `parseContentResponse(response, mode, expectedLanguage)`가 요청 언어를 받고(`AiLearningClient`), 저장 행을 읽을 때는 행의 `language` 열을 넘긴다(`toContentOrNull`, `SeasonCoordinator.parse`). JSON의 `language` 키는 폴백. 단위 테스트 `ContentLanguageTest` 추가.
- **[중] 레벨 창 언어 불일치**: `onSessionRecorded(mode, language, at)`로 세션의 언어를 함께 넘겨, 홈에서 언어를 바꾼 뒤 결과 효과가 재실행되어도 그 세션의 언어 창에만 집계된다.
- **[하] 기본 인자 `language = ENGLISH`**: 리포지토리·설정의 기본값은 테스트 편의로 유지. 운영 호출부는 전부 명시 전달 확인.
