# 005 AI 제공 방식 및 보안 결정

## 결정 요약

005의 제품 선택이 확정됐다. 이 결정으로 006 AI 콘텐츠 생성 연동 작업을 구현할 수 있다.

- AI 제공자는 OpenAI API 하나로 시작한다.
- 초기 기본 모델은 GPT-5.6 Terra다. 실제 모델 식별자는 `OPENAI_MODEL` 환경 설정으로 관리해 이후 변경할 수 있다.
- Android 앱에서 Supabase Edge Function을 호출하고, Edge Function이 OpenAI API를 호출한다.
- OpenAI API 키는 Edge Function의 비밀 설정으로 보관한다. Android APK, 앱 설정 파일, 저장소에 키를 넣지 않는다.
- OpenAI 요청과 응답은 구조화된 JSON 계약을 사용한다. 구체적인 필드와 검증 규칙은 006에서 정의한다.
- AI 사용 범위는 Conversation/Story 콘텐츠 생성과 문맥 기반 표현 뜻 설명이다. 복습 일정·중복 판정·데이터 저장 등은 앱의 일반 로직으로 처리한다.
- 생성 콘텐츠를 서버 DB에 보관하지 않는다. 필요한 학습 상태와 저장 표현은 기존 제품 원칙대로 기기의 Room에 저장한다. 로그인과 계정 기능은 추가하지 않는다.
- Edge Function은 입력 검증, timeout, 오류 응답 등 기본 보호 처리를 제공한다. 사용량·비용 최적화는 MVP 이후로 미룬다.

## 구현 시 적용할 경계

- 요청에는 선택한 모드, 현재 난이도, 생성에 필요한 복습 표현 등 작업에 필요한 최소 정보만 포함한다. 계정 식별자나 전체 학습 이력은 보내지 않는다.
- Edge Function은 허용된 모드와 입력 크기를 검증하고 `OPENAI_MODEL` 설정을 사용해 OpenAI에 요청한다.
- 함수 응답은 JSON으로 파싱하고 앱의 콘텐츠 도메인 모델로 변환한다. 잘못된 응답, timeout, 네트워크 및 제공자 오류를 구분해 화면에서 다시 시도할 수 있게 전달한다.
- 로그와 오류 응답에 API 키가 포함되지 않도록 한다. 함수 비밀값은 배포 환경에서 설정하며 저장소에 기록하지 않는다.
- 콘텐츠나 학습 기록을 Supabase DB에 저장하지 않는다. Supabase는 이 연동에서 Edge Function 실행 계층으로만 사용한다.

## 실무 작업 분해

1. 006에서 요청·응답 JSON schema와 앱 도메인 모델을 정한다. Conversation/Story 모드, 난이도, 필요한 복습 표현, 문맥 뜻 요청을 표현한다.
2. Supabase Edge Function을 추가한다. 필수 입력과 크기를 검증하고 `OPENAI_MODEL` 및 서버 secret을 사용해 OpenAI API를 호출한다.
3. 모델 출력을 JSON 형식에 맞게 검증하고, 비정상 출력은 앱에 일관된 오류로 반환한다. 서버 DB에는 생성 내용을 쓰지 않는다.
4. Android repository/client를 추가해 Edge Function을 호출하고 응답을 앱 모델로 변환한다. 앱 내에는 OpenAI key를 두지 않는다.
5. loading, timeout, 취소, 통신 오류, 잘못된 응답을 처리하고 사용자가 다시 시도할 수 있게 한다. 자동 재시도나 사용량 과금 정책은 임의로 확장하지 않는다.
6. 함수 입력 검증, JSON 변환, 앱 요청 매핑 및 실패 처리 테스트를 추가하고 lint/build를 실행한다.

## 준비 상태

제공자, 기본 모델, 키 보관 위치, 호출 경로, 데이터 저장 경계와 오류 처리 범위가 확정됐다. 005의 결정 작업은 정리됐으며 006에서 위 범위에 따라 구현을 시작할 수 있다. 비용 최적화는 MVP 이후로 미룬다.

## 2026-09-20 결정 변경: 제공자를 Anthropic으로 전환

사용자가 Anthropic 키를 보유하고 있어 제공자를 바꿨다. 이 항목은 위의 "AI 제공자는 OpenAI API 하나로 시작한다"와 "초기 기본 모델은 GPT-5.6 Terra"를 대체한다. 나머지 경계(키는 Edge Function secret에만 보관, 생성 콘텐츠를 서버 DB에 저장하지 않음, 앱에 키를 넣지 않음, 복습 일정과 중복 판정은 앱 로직)는 그대로 유지한다.

- 제공자는 Anthropic Messages API(`https://api.anthropic.com/v1/messages`)다. 인증은 `x-api-key` 헤더와 `anthropic-version: 2023-06-01`이다.
- 기본 모델은 `claude-sonnet-5`이며 `ANTHROPIC_MODEL` secret으로 바꿀 수 있다. 키는 `ANTHROPIC_API_KEY` secret에서만 읽는다.
- 구조화 출력은 `output_config.format`의 `json_schema`로 강제한다. OpenAI 전용이던 `store: false`와 스키마 `name` 필드는 제거했다.
- `stop_reason`이 `max_tokens`면 잘린 응답으로 보고 거부하고, `refusal`이면 `provider_refused`(502)로 변환한다. HTTP 429와 529는 `provider_busy`(503)로 묶는다.
- 핸들러 테스트 5건이 위 계약을 덮고 통과한다: `node --experimental-strip-types --test-isolation=none --test supabase/functions/ai-learning/index.test.mjs`.
