# 001 Android 앱 기반 구성

## 목적
요구사항의 Android Native, Kotlin, Jetpack Compose 기반을 세우고 지원 Galaxy에서 실행 가능한 첫 앱을 만든다.

## 작업 범위
- Gradle 및 모듈 구조, 패키지 규칙, 최소 지원 SDK를 정한다.
- Compose 기반 앱 진입점과 테마를 마련한다.
- Galaxy S24 이후 Galaxy S 계열 폼팩터를 우선 대상으로 빌드한다.
- 디버그 빌드를 실제 기기 또는 에뮬레이터에서 실행한다.

## 완료 기준
- 프로젝트가 빌드되고 앱이 실행된다.
- 초기 화면을 Compose로 렌더링한다.
- iOS, 태블릿, Fold/Flip 지원을 범위에 포함하지 않는다.

## 선행 작업
없음

## 관련 파일
- `요구사항/요구사항.md` — 지원 기기, Android Native/Kotlin/Compose, MVP 제외 범위와 실행 완료 기준의 기준 문서.
- `AGENTS.md` — 프로젝트 구조 원칙과 Android lint/build 검증 절차.

현재 저장소에는 `settings.gradle(.kts)`, 앱 모듈의 `build.gradle(.kts)`, Gradle wrapper, Android manifest, Kotlin/Compose 소스가 없다. 따라서 위 파일은 기존 참고 문서이며, 나머지는 이 작업에서 새로 만들 대상이다.

## 실행 순서
1. 요구사항에 맞춰 최소 SDK, 앱 ID/패키지, 단일 앱 모듈 중심의 Gradle 구성을 정하고 wrapper를 포함한다. 지원 기준은 Galaxy S24 이후 Galaxy S 계열로 두며 Fold/Flip, 태블릿, iOS는 별도 대응하지 않는다.
2. Android manifest와 Kotlin 앱 진입점을 만들고, Jetpack Compose의 단일 초기 화면과 기본 테마를 구성한다.
3. Android lint와 `assembleDebug`를 실행해 설정 및 소스 오류를 해결한다.
4. 사용 가능한 에뮬레이터 또는 실제 지원 기기에서 설치·실행하고 초기 Compose 화면 렌더링을 확인한다. 실행 환경이 없으면 빌드 결과와 기기 확인 제한을 구분해 기록한다.

## 현재 구현 결과
- 단일 `app` 모듈을 만들고 `com.englishquiz.app` 패키지를 사용한다. 아직 로그인, 네트워크, 데이터베이스는 넣지 않았다.
- `MainActivity`는 `EnglishQuizTheme` 안에서 Compose 초기 화면을 렌더링한다.
- Android Gradle Plugin 9.4.0, Gradle wrapper 9.6.0, AGP 내장 Kotlin 및 Compose compiler plugin 2.2.10, Compose BOM 2026.09.00으로 버전을 고정했다. AGP 내장 Kotlin과 플러그인 버전을 맞춰 중복 Kotlin 플러그인을 제거했다.
- `compileSdk`와 `targetSdk`는 API 37, `minSdk`는 Galaxy S24 출시 API인 34로 두었다. AGP 9.4 공식 호환성 표는 Gradle 9.6.0, JDK 17, 최대 API 37을 요구한다.
- Android Auto Backup과 기기 이전은 비활성화하고, 백업 규칙에서 앱 데이터 영역을 제외해 학습 데이터의 기기 내 저장 원칙을 유지한다.
- 현재 확인한 Kotlin/XML 소스는 모두 `.codex/line-limits.json`의 85% 경고선보다 짧다. 이후 작업 파일도 매번 다시 검사한다.

## 검증 기록 및 제한
- 2026-09-18: 설치된 JBR의 `java.exe -version`으로 OpenJDK 21.0.8을 확인했다. 작업 중 Android SDK에 API 37 플랫폼과 Build Tools 36.0.0을 추가 설치했다.
- 2026-09-18: 기존 로컬 Gradle 8.4로 `wrapper --gradle-version 8.4`를 실행해 wrapper 파일 생성을 확인했다. 이후 wrapper 배포판은 요구되는 9.6.0으로 갱신했다.
- 2026-09-18: 첫 `lint assembleDebug` 시도는 Build Tools 36.0.0 부재로 실패했으나, 이후 API 37 및 Build Tools 36.0.0 설치를 마쳤다. `:app:tasks --all` 구성 검사는 통과했다.
- 2026-09-18: Room entity 인덱스 필드 이름을 수정한 뒤 `:app:kspDebugKotlin lint assembleDebug compileDebugAndroidTestKotlin --no-daemon`이 53개 작업 성공으로 끝났다. 계측 테스트 APK의 소스 컴파일까지 성공했으나 실행 가능한 실기기 또는 에뮬레이터가 연결되지 않아 앱 설치·실행은 확인하지 못했다.
