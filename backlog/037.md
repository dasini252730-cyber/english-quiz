# 037 오늘의 미션 3개와 보너스 점수

## 목적
홈에 오늘의 미션 카드: 학습 1회 완료 / 퀴즈 정답률 80% 이상 / 새 표현 3개 저장. 오늘 세션 기록에서 계산하며 달성 시 보너스 점수(경험치)로 반영.

## 작업 범위
새로운 도메인 정책 `DailyMissionPolicy`로 오늘 세션 기록에서 3개 미션 계산 (학습 1회 완료 / 정답률 80% 이상 / 새 표현 3개 저장).
홈에 미션 카드 UI 추가하여 달성 상태 표시.
달성 시 보너스 점수(경험치) 반영은 백로그 040으로 보류.

## 구현 순서

1. **DailyMissionPolicy 작성** (`domain/game/DailyMissionPolicy.kt`)
   - Data class `DailyMission(title: String, description: String, isCompleted: Boolean)`
   - Data class `DailyMissions(missions: List<DailyMission>)`
   - Fun `computeMissions(todaysSessions: List<LearningSessionEntity>): DailyMissions`
   - 미션 1: `sessions.isNotEmpty()` → 학습 1회 이상 완료
   - 미션 2: `any session { quizCorrectCount / quizQuestionCount >= 0.80 && quizQuestionCount >= 3 }` → 정답률 80% 이상 (3개 이상 문제)
   - 미션 3: `sessions.sumOf { it.newlySavedExpressionCount } >= 3` → 새 표현 3개 이상 저장

2. **HomeMissionCard 작성** (`ui/HomeMissionCard.kt`)
   - Composable `MissionCard()`: 3개 미션 카드 렌더링
   - 각 미션별 체크박스/상태 아이콘 표시
   - HomeModeCard 패턴 참고하여 커스텀 색상/아이콘 적용

3. **HomeRoute 수정** (`ui/HomeRoute.kt`)
   - `LearningHomeSummary` → `produceState` 블록에서 `repository.findLearningSessions(todayIso())` 호출 추가
   - `DailyMissionPolicy.computeMissions()` 호출
   - `HomeSummary` 데이터 생성 시 `todaysMissions` 필드 추가

4. **HomeSummary 확장** (`ui/HomeScreen.kt`)
   - Data class `HomeSummary`에 `todaysMissions: DailyMissions?` 필드 추가
   - `HomeScreen` Composable에서 `SummaryTiles` 아래 `HomeMissionCard` 렌더링 추가

5. **HomeScreenTest 수정** (`ui/HomeScreenTest.kt`)
