# 041 주간 보스전(주말 한정 큰 퀴즈, 2배 점수)

## 목적
토·일에 홈에서 주 1회 열리는 보스전: 복습 예정+미암기 표현 최대 15문제, 점수 2배, mode='boss' 세션으로 기록(레벨 제안 제외). AI 호출 없음.

## 작업 범위
1. LearningDao에 보스전 후보 표현 조회 DAO 추가 (due 표현 + 미암기 표현, consecutiveCorrectCount 최소 순, 최대 15개)
2. QuizBuilder.build()에 maxQuestions 파라미터 추가 (보스전 15문제, 일반 10문제)
3. QuizRoute에 boss 플래그 추가 (2배 점수, enrolExpressions=false, todayContent=null)
4. ui/boss/BossRoute.kt 신규 작성 (보스전 퀴즈 → 결과 연결, sessionMode="boss")
5. EnglishQuizApp.suggestLevel()에서 boss 세션 필터링 (mode != "boss")
6. HomeScreen에 보스전 카드 추가 (토·일만, ISO 주 1회 제한)

## 완료 기준
- 보스전 카드가 홈에 표시됨 (토·일만, 주당 1회 제한)
- 보스전 진입 시 복습 예정 및 미암기 표현 최대 15문제로 퀴즈 생성
- 점수 2배 배수 적용됨 (ScorePolicy.answer에 multiplier=2 전달)
- mode='boss'로 세션 기록됨
- 보스 세션은 난이도 제안 대상에서 제외됨
- 보스전 후 홈으로 복귀
