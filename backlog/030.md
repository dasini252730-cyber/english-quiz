# 030 난이도 1/2/3 을 프롬프트 기준으로 구체화

## 발견 (2026-09-28)
사용자 질문("테스트 후에 레벨에 맞게 나오는 거지?")을 확인하다 발견. 흐름은 맞았다(진단 → 난이도 1/2/3 저장 →
생성 요청에 난이도 포함 → 013 이 세션마다 조절). 그러나 프롬프트는 "Match the supplied difficulty" 뿐이고 요청 JSON 에
숫자만 실려, 모델이 1/2/3 의 의미를 짐작해야 했다.

## 수정
`supabase/functions/ai-learning/index.ts`: `difficultyRubric(difficulty)` 를 계약(`passageContract`)에 포함.
- 1 초급: 최대 12단어의 짧고 단순한 문장, 고빈도 일상 어휘, 현재/단순과거, 관용구 최대 1개, 상황 유머.
- 2 중급: 자연스러운 길이(가끔 긴 문장), 원어민식 관용구·구동사, 톤 유머.
- 3 고급: 원어민 속도·리듬, 관용구·뉘앙스·말장난, 덜 흔한 어휘, 긴 문장 허용.
테스트: 난이도별 시스템 프롬프트에 해당 기준이 들어가는지(16/16). 배포 완료.

## 실측 (Conversation, 같은 상황)
```
난이도 1: 평균 8.3 단어/문장, 최대 13, 9자 이상 단어 8개  — "Hi Mina! How are you today?"
난이도 3: 평균 18.6 단어/문장, 최대 27, 9자 이상 단어 22개 — "Between work and everything else, I barely have time to breathe…", "burnt out", "make or break"
```
레벨 간 차이가 뚜렷하다. 표현 주석 수는 여전히 편차가 있다(1~5개, 028 참조).
