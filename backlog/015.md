### 주행 경로와 결과
```
최초 실행 -> 진단 8문항 -> 홈(0일/0개/0개) -> Conversation 생성(AI 정상) -> Reader
  -> 표현 터치 2건: 문맥 뜻 표시 + "복습함에 저장했어요"
  -> 퀴즈 2문항 정답 -> 결과(정답률 100%, 학습 2개, 새로 저장 2개, 1일 연속)
  -> 홈(1일/2개/0개) -> 강제 종료 -> 재실행: 지표 유지
  -> 복습함 2개, 다음 복습 2026.09.26 (간격 반복 정상)
```
006 을 막고 있던 Anthropic 크레딧 문제는 해소됐다. 생성·뜻 조회 모두 실제 응답을 받았다.

### 주행 중 발견하고 고친 결함 2건
1. **마지막 문항 버튼이 "다음 문제"였다.** 2/2 문항에서도 다음 문제가 있는 것처럼 보였다.
   `QuizScreen.kt` 에서 `questionNumber == totalQuestions` 일 때 "결과 보기" 로 바꿨다.
   `QuizScreenTest.theLastQuestionOffersTheResultScreenInsteadOfAnotherQuestion` 으로 고정했다.
2. **퀴즈 해설 문구가 이중으로 끝났다.** 모델이 주는 뜻은 이미 완결된 문장("…뜻입니다.")인데
   `"X" 은(는) '<뜻>' 라는 뜻이에요.` 템플릿이 한 번 더 감싸 `'…뜻입니다.' 라는 뜻이에요.` 로 보였다.
   AI 가 만든 모든 뜻이 그러므로 실사용에서 항상 나타난다. 표현과 뜻을 두 줄로 분리했다.
   `QuizBuilderTest.explanationKeepsTheModelsSentenceInsteadOfWrappingItInAnotherOne` 으로 고정했다.

### 함께 처리한 사용자 요청
- **런처 아이콘이 아예 없었다.** 매니페스트에 `android:icon` 이 없고 `mipmap` 리소스도 없어 기본
  안드로이드 아이콘이 떴다. adaptive icon(보라 배경 + 크림색 펼친 책 + 노란 책갈피)과 monochrome
  레이어를 만들어 연결했다. 런처와 스플래시에서 확인했다.
- **앱 이름을 `StoryEnglish` 로.** `strings.xml` 의 `app_name` 과 콜드 스타트 로딩 화면 제목을 바꿨다.
  `applicationId`(`com.englishquiz.app`)와 내부 식별자는 건드리지 않았다.
- 홈 헤더의 브랜드 표기 `몽글잉글`(017 디자인 시스템)은 그대로 두었다. 사용자 결정 대기.

- **제외 범위** — Fold/Flip/태블릿/iOS 는 요구사항상 대상이 아니며 테스트하지 않았다.
