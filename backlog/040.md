# 040 스트릭 보호권(점수로 구매, 하루 자동 적용)

## 목적
경험치 300점으로 보호권 구매(잔액=획득−사용). 하루 빠진 날이 생기면 자동으로 1장 소비해 스트릭 유지. 사용 날짜와 보유 수는 DataStore.

## 작업 범위
- 스트릭 보호권 구매: 300 XP를 보호권 1장으로 구매 (잔액 관리: 획득 - 사용)
- 자동 보호권 적용: 하루 빠진 날이 생기면 자동으로 보호권 1장 소비해 스트릭 유지
- DataStore에 저장: 보유 보호권 수, 소비한 총 XP, 사용한 날짜들
- 홈 레벨 카드에 "보호권 사기 (300점)" 버튼 추가
- 결과 화면에서 스트릭 판정 시 보호권 자동 소비 로직 추가

## 완료 기준
- StreakShieldPolicy.kt가 학습 날짜와 보호권 사용 날짜로부터 보호 가능한 빈 날짜를 판정함
- StreakPolicy.currentStreakDays가 학습 날짜와 보호된 날짜를 모두 받아 스트릭 계산
- AppSettingsRepository가 보호권 구매(XP 차감), 보호권 잔액, 사용한 날짜 관리
- 홈 화면의 모드 카드에서 보호권 구매 가능 (XP 300 이상일 때)
- 결과 화면에서 하루 빠진 날이 감지되면 자동으로 보호권 1장 소비
- AppSettingsRepositoryTest와 StreakPolicyTest에 새 기능 테스트 추가
