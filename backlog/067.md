# 067 중국어 1/6: Language 모델, 선택 언어·언어별 레벨 저장, 홈 English/中文 전환

## 목적
Language enum(en/zh), DataStore selected_language와 level_zh_<mode>(기본 3), AppSettings.level(language, mode), 홈 상단 언어 전환, 언어별 문구. 에픽 066의 A절.

## 작업 범위
- `data/ai/Language.kt`: `ENGLISH("en", Locale.US, "English")`, `CHINESE("zh", Locale.SIMPLIFIED_CHINESE, "中文")`, `korean`("영어"/"중국어"), `fromWire`.
- `AppSettingsRepository`: `selected_language` 키, `AppSettings.language`, 설정이 내보내는 `levels`는 선택 언어의 것. 영어 키는 그대로(`level_story`), 중국어는 `level_zh_story`. 중국어 기본 레벨 3, 진단 없음. 쓰기 함수들은 `language` 파라미터(기본 ENGLISH).
- 홈: `HomeLanguageToggle`(English/中文 세그먼트), `HomeScreen`/`HomeSummaryRoute`/`HomeRoute`/`EnglishQuizApp`에 언어 전달. 홈 타일(저장 표현·암기)은 선택 언어, 게임 통계는 전체 언어.
- `LearningSessionRoute`에 `language` 전달; 결과 화면 세션 행에 언어 기록.

## 결정
- 스트릭·점수·배지·미션은 공유(066 결정 1). `listAllSavedExpressions()`로 게임 계산.
- 중국어 진단 없음, 초기 3.

## 완료 기준
- 홈에서 전환이 저장되고 재실행 후 유지된다. 전환하면 레벨 표시·세션·복습함·라이브러리가 그 언어로 바뀐다.
- 영어 레벨 키와 값은 변경 전과 동일하게 읽힌다(DataStore 마이그레이션 없음).
