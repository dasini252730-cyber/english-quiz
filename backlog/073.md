# 073 TTS 자연스러움: 피치 변조 제거, 중국어 속도 0.9, 온라인 음성 토글, 로케일 매칭 로그

## 목적
모든 언어에서 화자 구분용 피치 변조를 끄고 음성이 모자라면 같은 음성을 1.0으로 재사용. 중국어 읽기 속도 0.9. 네트워크 음성 허용을 홈 설정 토글(기본 꺼짐)로. 앱 Locale과 엔진 음성 locale, 선택된 음성을 로그로 남기고 zh/cmn 표기 차이를 모두 후보로 허용.

## 작업 범위

1. **피치 변조 제거** (SpeakerVoices.kt)
   - assign() 함수에서 선택된 음성은 모두 DEFAULT_PITCH(1.0)으로 설정
   - fallbackPitch는 음성이 거부될 때만 사용 (현재 로직 유지)
   - 음성 부족 시 같은 음성을 pitch 1.0으로 재사용

2. **네트워크 음성 토글** (AppSettingsRepository.kt + HomeScreen.kt)
   - AppSettings에 allowNetworkVoices: Boolean 필드 추가 (기본값 false)
   - DataStore에 network_voices 불린 키 추가
   - HomeScreen에 "온라인 음성 사용" 토글 추가 및 상태 저장

3. **음성 필터링** (SpeakerVoices.kt)
   - assign() 함수 서명에 allowNetworkVoices 파라미터 추가
   - usable voices 필터링: requiresNetwork = true인 음성 제외 (allowNetworkVoices = false일 때)

4. **중국어 읽기 속도** (ReaderSpeech.kt)
   - play() 함수: language == Language.CHINESE일 때 setPitch 호출 후 setSpeechRate(0.9) 호출

5. **로케일 및 음성 선택 로깅** (ReaderSpeech.kt)
   - 지문 재생 시 로그: "voices: <plan>" (이미 DEBUG 로그 존재)
   - apply() 함수에서 로깅 추가: 앱 Locale (language.locale), 엔진이 선택한 음성의 locale (currentVoiceLocale), 선택된 음성 이름
   - 로그 포맷: "TTS: app_locale=<>, engine_voice_locale=<>, selected_voice=<name>"

6. **설정 전달 플럼빙**
   - HomeRoute에서 repository.settings 흐름으로 allowNetworkVoices 취득
   - ReaderRoute에서 AppSettings 파라미터 수신 후 ReaderSpeech 생성 시 전달
   - ReaderSpeech에서 play() 호출 시 allowNetworkVoices를 SpeakerVoices.assign()에 전달
   - QuizLearnCard, ReviewRoute도 동일하게 AppSettings 수신 후 ReaderSpeech에 전달

7. **zh/cmn 표기 차이 처리** (SpeechEngine.kt)
   - languageAliases() 함수가 이미 "zh", "cmn", "zho" 모두 후보로 반환함 (이미 구현됨)

- `AndroidSpeechEngine`: 음성 목록을 읽을 때 요청 Locale(zh/cmn/zho 별칭 포함), 매칭 수, 전체 음성의 locale을 `Log.i("SpeechEngine")`로 기록. `VoiceOption.locale` 추가.

## 구현 기록 (2026-10-18)
- `SpeakerVoices.assign(..., allowNetwork)`: 피치 변조 제거(전 언어). 음성이 부족하면 같은 음성을 1.0으로 재사용, 음성이 없으면 기본 음성. `VoiceChoice.pitch`는 항상 1.
- `ReaderSpeech(context, language, allowNetworkVoices)`: 중국어는 `zh_CN → cmn_CN → zh → cmn` 순으로 `setLanguage`를 시도. 성공 시 `Log.i`로 선택 로케일·각 시도 결과·해당 언어 음성 수를 남기고, 디버그 빌드에서는 엔진 전체 음성 목록(`name@locale`, 네트워크 표시)을 초기화 때 한 번 25개씩 나눠 기록. 전부 실패하면 `Log.w`로 결과를 남기고 엔진을 `zh_CN`으로 되돌린 뒤 안내 문구. 성공 뒤 `setSpeechRate(0.9 for zh, 1.0 otherwise)`.
- 음성 적용 로그: `apply()`가 `setVoice` 뒤 엔진의 실제 음성(`SpeechEngine.appliedVoice` = name@locale)을 읽어, 계획과 다르면 `Log.w`, 같으면 디버그 `Log.d`. 릴리스 빌드에는 Log.i 요약과 경고만 남음.
- 오프라인 폴백: `UtteranceProgressListener.onError(id, errorCode)`가 `ERROR_NETWORK`/`ERROR_NETWORK_TIMEOUT`(API 21+)이면 이 리더를 설치 음성 전용으로 바꾸고 같은 줄을 다시 재생하며 "온라인 음성에 연결하지 못해 기기에 설치된 음성으로 읽어요."를 표시. 그 외 오류는 기존 실패 처리.
- 설정: `network_voices`(기본 false) → `AppSettings.allowNetworkVoices`, 홈 `HomeNetworkVoiceToggle` → 리더·퀴즈 카드·복습함 `ReaderSpeech`.
- 테스트: `SpeakerVoicesTest`(피치 1 고정, 네트워크 허용), `ReaderSpeechVoicesTest`(거부 시 기본 1.0, 음성 1개 재사용, zh 0.9/en 1.0, 토글 전달, 네트워크 오류 폴백), `ReaderSpeechLanguageTest`(cmn 폴백 성공, 전부 실패 시 zh_CN 복원), `AppSettingsNetworkVoicesTest`(기본 꺼짐·저장).

## 확인 방법 (실기)
