# 039 배지(업적) 10종과 배지 화면

## 완료 기준

- 10가지 배지 조건이 모두 정의되고 BadgePolicy에 구현됨
- 각 배지 조건을 계산하는 earned() 함수가 정확하게 동작
- AppSettingsRepository에서 badges_seen을 DataStore에 저장/로드 가능
- BadgeScreen이 홈에서 접근 가능하고 모든 배지를 표시함
- 결과 화면에서 새로 획득한 배지 표시 (earned - seen)
- 배지를 한 번 보면 다시 표시되지 않음 (badges_seen에 저장)
- 린트 및 빌드 통과
- 테스트 작성 및 통과
