# 071 중국어 4/6: 리더 토큰화·병음 표시·zh-CN TTS

## 목적
zh 토큰화(표시 어구→용어집 최장 일치→글자), 토큰 간격 0, CJK 문장부호, 화자 我, 표현 병음 표시와 줄 병음 토글(기본 꺼짐), SpeechEngine 언어 파라미터와 zh 보이스, 음성 없음 안내. 에픽 066의 D절.

## 작업 범위
- `ReaderTokens.tokenize(…, language, knownWords)` + `ChineseTokens.kt`: 표시 어구 → knownWords 최장 일치 → 글자 단위, CJK 문장부호는 탭 불가.
- `ReaderSegments`: zh 토큰 간격·패딩 0, `showPinyin`이면 줄 병음을 글자 위에 표시. `ReaderScreen`: 중국어 지문에 "拼音" 토글(기본 꺼짐, 회전 시 유지). `ReaderRoute`: knownWords = 용어집 + 저장 표현.
- `MeaningOverlay.Success.pinyin`: 표현 병음을 표현 아래에 표시. 퀴즈 학습 카드도 표시(070).
- `SpeechEngine`/`ReaderSpeech(context, language)`: `language.locale`, 보이스 필터 `locale.language`, 안내 "중국어 음성을 사용할 수 없어요…". 리더·퀴즈·복습함의 엔진에 언어 전달.
- `rightHandSpeaker`에 "我".

## 결정
- 줄 병음 토글은 화면 상태(rememberSaveable)로만 유지한다. 설정 저장은 보류(요청 시 추가).

## 완료 기준
- 중국어 지문이 글자 사이 공백 없이 그려지고, 표시 어구·용어집 단어·개별 글자를 탭할 수 있다.
- 拼音 토글로 줄 병음이 켜지고 꺼진다. 뜻 시트와 학습 카드에 병음이 보인다.
- S26에서 zh-CN 음성으로 전체·문장·표현 재생(기기 확인 필요).

## 리뷰 반영 (2026-10-18, code-critic)
- 용어집 단어를 탭하면 병음이 없던 결함: `localPinyinFor`가 표현 → 용어집 순으로 접힌 키(`foldTypography` + 가장자리 문장부호 제거)로 찾는다.
- `SegmentTokens`의 `modifier`를 첫 선택 인자로 옮겨 lint `ModifierParameter` 경고 해소. 줄 병음은 글자 위(교재식).
- 세션은 `key(language)`로 감싸 홈에서 언어를 바꾼 직후 탭이 이전 언어로 시작되는 레이스를 막음(HomeRoute). 언어가 바뀌면 스토리 레벨 안내 문구 초기화.
- `LearningSessionRoute`가 `QuizRoute`에 세션 언어를 명시 전달(콘텐츠 언어와 두 소스가 되지 않도록).
