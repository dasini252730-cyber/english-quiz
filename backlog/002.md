# 002 로컬 데이터 저장 기반

## 목적
로그인이나 클라우드 동기화 없이 앱을 종료해도 개인 학습 기록이 기기에 보존되게 한다.

## 작업 범위
- Room에 저장 표현, 문맥 뜻, 최초 저장일, 최근/다음 복습일, 연속 정답, 오답 기록을 저장한다.
- 학습 세션/완료 기록 및 스트릭 산출에 필요한 날짜별 기록을 저장한다.
- DataStore에 진단 완료 여부, 현재 난이도 등 간단한 앱 상태를 저장한다.
- 동일 표현 재선택 시 기존 표현을 찾아 최초 저장일과 복습 상태를 보존한다.

## 완료 기준
- 저장 후 앱 재시작 시 학습 기록과 앱 상태가 복원된다.
- 동일 표현을 다시 저장해도 중복 row가 생성되지 않는다.
- Supabase, 인증, 계정별 데이터 분리는 포함하지 않는다.

- `app/src/main/kotlin/com/englishquiz/app/data/` — Room entity/DAO/database, repository 및 DataStore 구현을 둘 새 패키지.

## 실무 작업 순서
1. 최소 스키마를 정한다. 표현은 정규화한 표현 키에 unique index를 두고, 문맥 뜻·첫 저장 시각·최근/다음 복습일·연속 정답·오답 횟수·암기 완료 상태를 둔다. 날짜별 학습 완료와 스트릭 계산에 필요한 세션 기록은 별도 테이블로 저장한다.
2. Room entity, DAO, database를 구현한다. 표현 재저장은 insert-ignore/upsert 후 기존 row를 조회하는 흐름으로 처리해 최초 저장일과 복습 정보를 덮어쓰지 않도록 한다.
3. DataStore Preferences를 구현해 진단 완료 여부와 현재 난이도처럼 작고 단순한 앱 상태를 보관한다.
4. Room/DataStore 접근을 repository 또는 명확히 분리된 저장소 API로 감싸고 앱 시작 지점에서 주입한다. 화면에서 직접 DB를 호출하지 않는다.
5. 영속화와 중복 저장을 검증하는 테스트를 추가한다. 최소한 중복 표현이 한 row만 남기고 기존 복습 상태를 보존하는지 확인한다.
6. `./gradlew.bat lint assembleDebug`를 실행하고, 가능한 경우 앱 재시작을 포함한 기기 검증을 수행한다.

## 현재 구현 상태
- 선행 작업 001에서 단일 `app` 모듈과 Compose 진입 화면을 만들었다.
- Room/DataStore 의존성과 데이터 계층, entity/DAO 및 저장소 연결이 구현돼 있다. 현재 구조와 검증 결과는 아래 구현 결과 및 검증 기록을 기준으로 한다.
- Android 백업 설정은 명시적으로 비활성화되어 있어 개인 데이터의 클라우드 백업/기기 전송 제외 정책과 일치한다. 변경 시 이 조건을 유지한다.
- schema v1의 기존 날짜별 세션 row를 보존하도록 v1→v2 명시 migration을 추가했다. 이후 변경도 destructive migration 없이 명시적으로 관리한다.

## 구현 시 경계
- 학습 기록은 Room, 진단 완료 여부와 현재 난이도 등 간단한 앱 상태는 DataStore에만 저장한다.
- 표현 키의 대소문자/공백 정규화 규칙은 중복 방지 목적에 필요한 최소 규칙으로 정의하되, 원래 표시 문자열과 문맥 뜻은 보존한다.
- 복습 시점과 스트릭 계산 규칙 자체는 이 저장 계층에서 새로 발명하지 않는다. 기존 요구사항/후속 학습 로직이 제공하는 값을 기록한다.
- Supabase, 계정, 인증, 동기화, AI 호출은 이 작업에 포함하지 않는다.

## 구현 결과
- `SavedExpressionEntity`는 정규화 표현 키의 unique index와 원문 표현, 문맥 뜻, 최초 저장일, 최근/다음 복습일, 정답 연속 수, 오답 수, 암기 완료 상태를 Room에 저장한다.
- `LearningSessionEntity`는 완료 세션마다 자동 ID를 부여하고 날짜 인덱스를 둬, 한 날짜에 여러 세션이 기록돼도 앞 기록을 덮지 않는다. 스트릭 산출 규칙은 포함하지 않고 후속 기능이 날짜별 세션을 집계한다.
- `recordCompletedSession`은 세션을 transaction 안에서 insert한다. 날짜별 조회는 완료 시각과 ID 순으로 모든 세션을 반환한다.
- schema v2 migration은 기존 날짜별 단일 세션 행을 새 자동 ID 테이블로 복사하고 날짜 인덱스를 만든다. 기존 행의 값은 유지된다.
- `LearningRepository.saveExpression`은 공백을 하나로 줄이고 소문자로 바꾼 키로 insert-ignore를 수행한다. 같은 표현이면 기존 row를 반환하므로 최초 저장일, 문맥 뜻, 복습 상태를 덮어쓰지 않는다.
- `AppSettingsRepository`는 Preferences DataStore에 진단 완료 여부와 현재 난이도를 저장한다. 읽기 오류는 빈 기본값으로 오인시키지 않고 UI 오류·재시도로 전달한다.
- `EnglishQuizApplication`의 `AppContainer`가 Room과 DataStore 저장소를 생성하며 화면은 저장소를 직접 호출하지 않는다.
- Room schema 출력 경로는 `app/schemas`다. v1과 v2 schema JSON을 저장소에서 관리한다.
